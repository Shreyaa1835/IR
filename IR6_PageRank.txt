# 2. Concepts Used in This Practical

### 1. Graph

A graph is a mathematical structure consisting of:

- Vertices (Nodes): Represent objects.
- Edges: Represent connections between objects.

Example: In a website network, each webpage is represented by a node and each hyperlink is represented by an edge.

### 2. Directed Graph

A directed graph is a graph in which edges have a specific direction.

For example:

\\[ A \rightarrow B \\]

This means page A links to page B.

But it does not necessarily mean page B links back to page A.

External question: What is the difference between directed and undirected graphs?

| Directed Graph            | Undirected Graph              |
| ------------------------- | ----------------------------- |
| Edges have directions.    | Edges do not have directions. |
| Represented using arrows. | Represented using lines.      |
| Example: Webpage links.   | Example: Mutual friendship.   |

### 3. PageRank Algorithm

PageRank is an algorithm originally developed by Google co-founders Larry Page and Sergey Brin to measure the importance of webpages.

It determines the importance of a webpage based on the links pointing towards it.

Main idea: A webpage is considered important if other important webpages link to it.

For example:

- If page A links to page B, page B receives a contribution to its PageRank.
- If an important page links to another page, that link carries more importance.
- A page receiving links from several important pages can achieve a high PageRank score.

### 4. Basic PageRank Formula

\\[ PR(A)=\frac{1-d}{N} +d\sum\_{T_i\rightarrow A}\frac{PR(T_i)}{C(T_i)} \\]

Where:

| Symbol       | Meaning                                      |
| ------------ | -------------------------------------------- |
| \\(PR(A)\\)  | PageRank of page A                           |
| \\(d\\)      | Damping factor                               |
| \\(N\\)      | Total number of pages                        |
| \\(T_i\\)    | Pages linking to page A                      |
| \\(C(T_i)\\) | Number of outgoing links from page \\(T_i\\) |

### 5. Damping Factor

The damping factor represents the probability that a user continues clicking links rather than jumping to a random webpage.

In this practical:

\\[ d=0.85 \\]

This means:

- 85% probability of following a link.
- 15% probability of jumping to a random page.

Why is the damping factor used?

It prevents the PageRank calculation from depending only on link structure and helps handle situations such as pages with no outgoing links.

### 6. In-degree and Out-degree

In-degree: Number of incoming edges to a node.

Out-degree: Number of outgoing edges from a node.

Example:

If:

\\[ A\rightarrow B,\quad A\rightarrow C \\]

Then:

- Out-degree of A = 2.
- In-degree of B = 1.
- In-degree of C = 1.

External question: Which is more important in PageRank, in-degree or out-degree?

Answer: Both the number and importance of incoming links matter. PageRank also considers how the linking pages distribute their scores among their outgoing links.

### 7. NetworkX

NetworkX is a Python library used to create, manipulate, analyze and visualize graphs and networks.

It supports:

- Directed graphs.
- Undirected graphs.
- Graph algorithms.
- Centrality calculations.
- PageRank.

### 8. Graph Visualization

Graph visualization means representing nodes and edges graphically.

In this practical:

- Nodes represent webpages.
- Arrows represent hyperlinks.
- The direction of an arrow indicates the direction of the link.

# 8. Important Technical Points

### 1. Why do D and E have equal PageRank scores?

Both D and E have no incoming links and have no outgoing links in this graph. Under NetworkX's standard PageRank handling of dangling nodes, their scores are equal.

### 2. Why does C have a high PageRank?

C receives incoming links from A, B, D and E. It receives PageRank contributions from all four nodes.

### 3. Why does A have the highest PageRank?

A receives links from C and D. In particular, C has a high PageRank score, so its link contributes significantly to A's score.

### 4. What happens if alpha is changed?

Changing alpha changes the balance between following links and randomly jumping to another node. Therefore, PageRank scores may change.

### 5. What happens if a node has no outgoing edges?

It is called a dangling node. NetworkX handles dangling nodes by redistributing their PageRank contribution according to its dangling-node handling rules (uniformly by default).

### 6. Does PageRank calculate the shortest path?

No. PageRank calculates node importance. Shortest-path algorithms calculate the minimum-distance route between nodes.

### 7. Is PageRank the same as counting incoming links?

No. A simple incoming-link count treats all incoming links equally. PageRank considers the PageRank scores of the linking pages and their outgoing links.
