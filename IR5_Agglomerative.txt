# 2. Concepts Used in This Practical

### 1. Clustering

Clustering is an unsupervised Machine Learning technique used to group similar data points into clusters.

Data points in the same cluster are more similar to each other than to data points in other clusters.

Example:

A shopping mall wants to group customers based on their:

- Annual income.
- Spending score.

It can identify groups such as:

- High-income, high-spending customers.
- High-income, low-spending customers.
- Low-income, high-spending customers.

### 2. Unsupervised Learning

Unsupervised Learning is a Machine Learning technique in which the model learns patterns from data without predefined output labels.

In this practical:

- Input: Annual income and spending score.
- Output: Customer clusters generated by the algorithm.

External question: What is the difference between supervised and unsupervised learning?

| Supervised Learning           | Unsupervised Learning           |
| ----------------------------- | ------------------------------- |
| Uses labelled data.           | Uses unlabelled data.           |
| Has predefined target values. | Does not require target values. |
| Example: Spam classification. | Example: Customer clustering.   |

### 3. Hierarchical Clustering

Hierarchical Clustering is an unsupervised learning algorithm that groups data points into a hierarchy of clusters.

It creates a tree-like structure called a dendrogram.

There are two main types:

A. Agglomerative Clustering (Bottom-Up)

- Starts with every data point as an individual cluster.
- Repeatedly merges the closest clusters.
- Continues until the required number of clusters is reached.

B. Divisive Clustering (Top-Down)

- Starts with all data points in one cluster.
- Repeatedly divides clusters into smaller clusters.

This practical uses Agglomerative Clustering.

### 4. Agglomerative Clustering

Agglomerative Clustering is a bottom-up hierarchical clustering algorithm.

Working:

1. Initially, every customer is considered a separate cluster.
2. The distance between clusters is calculated.
3. The closest clusters are merged.
4. This process continues until the required number of clusters is obtained.

External question: Why is it called bottom-up clustering?

Answer: Because it starts with individual data points and gradually combines them into larger clusters.

### 5. Standardization

Standardization is a data preprocessing technique used to bring numerical features onto a comparable scale.

In this practical, we use:

`StandardScaler()`

Formula:

\\[ Z=\frac{X-\mu}{\sigma} \\]

Where:

- \\(X\\) = Original value.
- \\(\mu\\) = Mean of the feature.
- \\(\sigma\\) = Standard deviation.
- \\(Z\\) = Standardized value.

After standardization:

- Mean is approximately 0.
- Standard deviation is approximately 1.

Why is standardization required?

Annual income and spending score have different numerical scales. Standardization prevents a feature with larger numerical values from dominating the distance calculation simply because of its scale.

### 6. Euclidean Distance

Euclidean Distance measures the straight-line distance between two data points.

Formula:

\\[ d(A,B)=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2} \\]

It is used to measure the similarity or dissimilarity between customers.

A smaller distance indicates that two customers are closer in the feature space.

### 7. Linkage

Linkage determines how the distance between two clusters is calculated.

Common linkage methods include:

| Linkage  | Meaning                                                                        |
| -------- | ------------------------------------------------------------------------------ |
| Single   | Minimum distance between points in two clusters.                               |
| Complete | Maximum distance between points in two clusters.                               |
| Average  | Average distance between points in two clusters.                               |
| Ward     | Merges clusters that produce the smallest increase in within-cluster variance. |

This practical uses Ward linkage.

Ward linkage tries to combine clusters while minimizing the increase in within-cluster sum of squares.

### 8. Dendrogram

A dendrogram is a tree-like diagram used to visualize the merging process in hierarchical clustering.

It shows:

- Which data points or clusters are merged.
- The order in which clusters are merged.
- The distance at which clusters are combined.

The vertical height represents the linkage distance at which two clusters are merged.

Why is a dendrogram used?

It helps us understand the hierarchical structure and choose a suitable number of clusters by examining where to cut the tree.

### 9. Scatter Plot

A scatter plot is a graph used to display the relationship between two numerical variables.

In this practical:

- X-axis = Standardized annual income.
- Y-axis = Standardized spending score.
- Colour = Assigned cluster.

It helps us visually understand how customers are grouped.

## Step 5: Standardizing the Data

Line 9:

`X_scaled = scaler.fit_transform(X)`

This line performs two operations:

1\. `fit()`

- Calculates the mean and standard deviation of each feature.
- Learns the scaling parameters from the dataset.

2\. `transform()`

- Applies standardization to the original feature values.
- Converts them into standardized values.

The formula is:

\\[ Z=\frac{X-\mu}{\sigma} \\]

Example:

Suppose the annual income of a customer is 60, the mean is 50 and the standard deviation is 10.

\\[ Z=\frac{60-50}{10}=1 \\]

The standardized value becomes 1.

External question: What is the difference between fit() and transform()?

Answer:

- `fit()` learns the mean and standard deviation.
- `transform()` applies the learned scaling parameters to the data.

External question: What is the shape of X_scaled?

Answer: It has the same number of rows and columns as X. It contains one standardized value for each selected feature of every customer.

## Step 6: Creating the Linkage Matrix

Line 10:

`linked = linkage(X_scaled, method="ward")`

This is an important line.

- `linkage()` performs hierarchical clustering calculations.
- It calculates how clusters should be merged.
- `X_scaled` provides the standardized customer data.
- `method="ward"` selects Ward's linkage method.
- The resulting hierarchical structure is stored in `linked`.

What does Ward linkage do?

Ward linkage merges clusters in a way that produces the smallest increase in within-cluster variance.

In simple words, it tries to combine clusters while keeping their members relatively similar.

External question: What is a linkage matrix?

Answer: A linkage matrix stores information about which clusters are merged, the distance between them and the number of observations in the resulting cluster.

# 5. Complete AIM-Based Theory

### Q1. What is Clustering?

Clustering is an unsupervised Machine Learning technique used to group similar data points based on their characteristics.

### Q2. What is Hierarchical Clustering?

Hierarchical Clustering is an unsupervised algorithm that creates a hierarchy of clusters represented using a dendrogram.

### Q3. What are the types of Hierarchical Clustering?

There are two main types:

1. Agglomerative Clustering – Bottom-up approach.
2. Divisive Clustering – Top-down approach.

### Q4. What is Agglomerative Clustering?

Agglomerative Clustering is a bottom-up clustering technique that initially treats every data point as a separate cluster and repeatedly merges the closest clusters.

### Q5. What is Divisive Clustering?

Divisive Clustering is a top-down clustering technique that starts with all data points in one cluster and repeatedly divides them into smaller clusters.

### Q6. What is the difference between Agglomerative and Divisive Clustering?

| Agglomerative                        | Divisive                       |
| ------------------------------------ | ------------------------------ |
| Bottom-up approach.                  | Top-down approach.             |
| Starts with individual clusters.     | Starts with one large cluster. |
| Merges clusters.                     | Splits clusters.               |
| Commonly used hierarchical approach. | Less commonly used.            |

### Q7. What is a Dendrogram?

A dendrogram is a tree-like diagram that represents the merging or splitting of clusters in hierarchical clustering.

It helps visualize the hierarchical relationships and choose the number of clusters.

### Q8. What is Linkage?

Linkage is the method used to calculate the distance between two clusters.

Common methods include:

- Single linkage.
- Complete linkage.
- Average linkage.
- Ward linkage.

### Q9. What is Ward Linkage?

Ward linkage merges two clusters that produce the smallest increase in within-cluster sum of squares.

It tries to keep the clusters compact.

### Q10. What is Euclidean Distance?

Euclidean Distance is the straight-line distance between two points in a multidimensional space.

For two-dimensional data:

\\[ d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2} \\]

### Q11. What is Standardization?

Standardization transforms numerical data so that each feature has approximately zero mean and unit standard deviation.

Formula:

\\[ Z=\frac{X-\mu}{\sigma} \\]

### Q12. Why is StandardScaler used?

It brings numerical features onto comparable scales.

Without standardization, annual income could have a greater influence on distance calculations because of its numerical scale compared with spending score.

### Q13. What is the difference between Normalization and Standardization?

| Normalization                                             | Standardization                                         |
| --------------------------------------------------------- | ------------------------------------------------------- |
| Commonly scales values into a fixed range such as 0 to 1. | Centers values around mean 0 with standard deviation 1. |
| Often uses minimum and maximum values.                    | Uses mean and standard deviation.                       |
| Example: MinMaxScaler.                                    | Example: StandardScaler.                                |

### Q14. What is the difference between K-Means and Hierarchical Clustering?

| K-Means                                                | Hierarchical Clustering                                     |
| ------------------------------------------------------ | ----------------------------------------------------------- |
| Partitional clustering algorithm.                      | Hierarchical clustering algorithm.                          |
| Requires the number of clusters in advance.            | Can use a dendrogram to help choose the number of clusters. |
| Uses centroids.                                        | Uses linkage between clusters.                              |
| Iteratively updates cluster assignments and centroids. | Repeatedly merges or splits clusters.                       |
| Does not naturally produce a dendrogram.               | Produces a dendrogram.                                      |

### Q15. What is the difference between Supervised and Unsupervised Learning?

| Supervised Learning                      | Unsupervised Learning                    |
| ---------------------------------------- | ---------------------------------------- |
| Uses labelled data.                      | Uses unlabelled data.                    |
| Predicts known target classes or values. | Finds hidden patterns or groups.         |
| Classification and regression.           | Clustering and dimensionality reduction. |

### Q16. What is the purpose of `n_clusters=5`?

It specifies that the algorithm should divide the customers into five final clusters.

### Q17. What is `fit_predict()`?

It fits the clustering model to the dataset and returns a cluster label for every data point.

5. Market research.
6. Social network analysis.

It is an unsupervised Machine Learning technique because it does not require predefined class labels.

# 10. Important Technical Points and Limitations

### 1. Does the program use CustomerID for clustering?

No. It uses only:

- Annual Income.
- Spending Score.

CustomerID is displayed only to identify customers.

### 2. Why do we standardize the features before clustering?

Because the algorithm uses distances to determine similarity.

If features have different scales, the feature with larger numerical values may dominate the distance calculation.

Standardization makes both features comparable.

### 3. Why do we create a dendrogram before applying clustering?

The dendrogram helps us understand how clusters are merged and provides guidance for selecting the number of clusters.

In this code, the number of clusters is explicitly set to five.

### 4. Does the dendrogram itself create the final five clusters?

No. The `dendrogram()` function only visualizes the hierarchical merging structure.

The actual cluster assignments are generated by:

`model.fit_predict(X_scaled)`

### 5. What is the difference between `linkage()` and `AgglomerativeClustering()`?

| `linkage()`                                    | `AgglomerativeClustering()`                              |
| ---------------------------------------------- | -------------------------------------------------------- |
| From SciPy.                                    | From Scikit-learn.                                       |
| Calculates the hierarchical merging structure. | Creates the clustering model and assigns cluster labels. |
| Used to draw the dendrogram.                   | Used to generate the final clusters.                     |

Both use Ward linkage in this practical, but they are separate computations.

### 6. What is the meaning of cluster 0, 1, 2, 3 and 4?

These are simply cluster identifiers assigned by the algorithm.

They do not indicate ranking or priority.

For example, cluster 0 does not automatically mean low-income customers.

We must examine the average income and spending score of each cluster to understand its customer characteristics.

### 7. What is the limitation of Agglomerative Clustering?

- It can become computationally expensive for large datasets.
- It can be sensitive to the choice of distance and linkage method.
- Once two clusters are merged, the standard agglomerative process does not undo that merge.

### 8. Why does the scatter plot show standardized values?

Because the program plots `X_scaled`, not the original `X`.

Therefore, the coordinates are standardized values.

For clearer axis labels, you could use:

```
plt.xlabel("Standardized Annual Income")plt.ylabel("Standardized Spending Score")
```

### 9. Can we use more than two features?

Yes. Agglomerative Clustering can work with more than two features. However, this particular scatter plot visualizes only two dimensions.

### 10. How can we understand the characteristics of each customer cluster?

We can calculate the average income and spending score for each cluster using:

```
df.groupby("Cluster")[    ["Annual Income (k$)", "Spending Score (1-100)"]].mean()
```

This helps us interpret the customer groups, such as high-income/high-spending or low-income/low-spending customers.
