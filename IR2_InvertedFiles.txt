# Practical: Implementation of Inverted Indexing for Information Retrieval

## 1. AIM

To implement an **Inverted Index** using Python and NLTK to retrieve relevant documents based on a user's search query.

The practical involves:
1. Creating a collection of documents.
2. Converting text into lowercase.
3. Extracting individual words using regular expressions.
4. Removing stop words.
5. Creating an inverted index.

# 2. Concepts Used in This Practical

### 1. Information Retrieval (IR)

Information Retrieval is the process of finding relevant documents or information from a large collection based on a user's search query.

**Example:** When you search for "Python programming" on Google, it retrieves webpages related to Python programming.

### 2. Inverted Index

An inverted index is a data structure that stores each word along with the list of documents in which that word appears.

It works in the opposite way to a normal document index.

**Example:**

Suppose we have two documents:

- Document 1: Python is easy.
- Document 2: Python is popular.

The inverted index will be:

| Word | Document IDs |
|---|---|
| Python | 1, 2 |
| easy | 1 |
| popular | 2 |

**Why is it used?**

Instead of checking every document word by word during a search, the system directly looks up the word in the inverted index.

This makes document searching faster and more efficient.

### 3. Regular Expressions (Regex)

Regular expressions are patterns used to search, extract or manipulate text.

In this practical, regex extracts only lowercase English words.

Example:

```text
"Hello! Python 123"
```

Output:

```text
['hello', 'python']
```

### 4. Stop Word Removal

Stop words are commonly used words that generally carry less importance for many information retrieval tasks.

Examples: `is`, `the`, `a`, `and`, `for`, `in`.

These words are removed to avoid storing unnecessary terms in the inverted index.

### 5. defaultdict

`defaultdict` is a special dictionary provided by Python's `collections` module.

It automatically creates a default value when a new key is accessed.

In this practical:

```python
inverted_index = defaultdict(list)
```

It automatically creates an empty list for a new word.

**Example:**

When the word `"information"` is accessed for the first time, Python automatically creates:

```python
'information': []
```

We can then add document IDs to that list.

### 6. Document Retrieval

Document retrieval means finding and displaying documents that contain the words entered by the user.

For example, if the user searches for `"information"`, the system retrieves all documents containing that word.

|---|---|
| `r` | Raw string |

| `\b` | Ending word boundary |

**Example:**


Output:


Numbers and punctuation are ignored.

**External question: What is the difference between findall() and sub()?**

Answer:
- `findall()` extracts all matching patterns and returns them in a list.
- `sub()` replaces matching patterns with another value.

# 5. Complete AIM-Based Theory

### Q1. What is an Inverted Index?

An inverted index is a data structure that maps each unique term to the list of document IDs in which that term appears.

It is commonly used in search engines to retrieve relevant documents efficiently.

### Q2. Why is an Inverted Index used?

It improves search efficiency because the system can directly find documents associated with a search term instead of scanning every document.

### Q3. What is the difference between a Forward Index and an Inverted Index?

| Forward Index | Inverted Index |
|---|---|
| Maps documents to their words. | Maps words to their documents. |
| Stores words against each document. | Stores document IDs against each word. |
| Document → Words | Word → Documents |
| Example: Doc 1 → Python, AI | Example: Python → Doc 1, Doc 2 |

### Q4. What is a Posting List?

A posting list is the list of document IDs associated with a particular word in an inverted index.

Example:

```text
information : [1, 2, 4]
```

Here, `[1, 2, 4]` is the posting list.

### Q5. What is a Term?

A term is an individual word or token extracted from a document and stored in the index.

Example: `information`, `retrieval`, `document`.

### Q6. What is a Document ID?

A Document ID is a unique identifier assigned to each document.

In this practical, the IDs are 1, 2, 3 and 4.

### Q7. What is the difference between AND and OR retrieval?

| AND Retrieval | OR Retrieval |
|---|---|
| Retrieves documents containing all query words. | Retrieves documents containing at least one query word. |
| More restrictive. | Less restrictive. |
| Uses intersection. | Uses union. |

**Example:**

Query: `information retrieval`

- AND: Only documents containing both words.
- OR: Documents containing information OR retrieval.

**Our practical uses OR retrieval.**

### Q8. What is the role of Stop Word Removal in Information Retrieval?

It removes frequently occurring words that may not contribute much to search relevance, reducing the number of terms stored in the index.

### Q9. What are the applications of Inverted Indexing?

1. Search engines.
2. Digital libraries.
3. Document search systems.
4. E-commerce product search.
5. Enterprise document management.
6. Information retrieval systems.

### Q10. Does this program rank documents according to relevance?

No. This program only retrieves documents based on matching query words. It does not calculate relevance scores or rank documents by importance.

### Q11. What happens if the user enters a word that does not exist in the index?

The word is ignored. If none of the query words match, the program displays `"No documents found."`

### Q12. What is the difference between an Inverted Index and a Database?

A database stores structured information and supports different types of queries. An inverted index is a specialized data structure designed to efficiently search text terms and identify documents containing them.

## 10. Important Technical Points to Remember

1. **Inverted Index:** Maps words to document IDs.
2. **defaultdict(list):** Automatically creates an empty list for new words.
3. **re.findall():** Extracts words using a regular expression.
4. **set(words):** Prevents duplicate document IDs for repeated words in one document.
5. **stopwords:** Removes common English words.
6. **update():** Adds matching document IDs to the result set.
7. **OR Retrieval:** Retrieves documents containing at least one query word.
8. **No Ranking:** The program does not calculate relevance scores.

**One important limitation:** This implementation does not apply stemming or lemmatization. Therefore, words such as `search` and `searching` are treated as different terms. Also, because it uses OR retrieval, a document matching only one query word is still returned.
