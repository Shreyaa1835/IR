# 2. Concepts Used in This Practical

### 1. Bayesian Network

A Bayesian Network is a probabilistic graphical model that represents relationships between variables using a **Directed Acyclic Graph (DAG)**.

It uses probability to represent uncertainty and make predictions.

**Example:**

Suppose we want to predict heart disease using:
- Age
- Cholesterol
- Blood pressure
- Maximum heart rate

These features are connected to the target variable, which represents heart disease status.

In this practical, the structure is:

```text
       Age ─────────┐
       Cholesterol ─┤
       Blood Pressure ─┤
       Heart Rate ────┤
                      ↓
                Heart Disease
```

Each medical feature is a parent of the target variable.

**External question: What is a Bayesian Network?**

Answer: A Bayesian Network is a probabilistic graphical model that represents dependencies between variables using a directed acyclic graph and conditional probability distributions.

### 2. Bayes' Theorem

Bayes' Theorem calculates the probability of an event based on previously available information.

Formula:

\[
P(A|B)=\frac{P(B|A)\times P(A)}{P(B)}
\]

Where:

- \(P(A|B)\): Probability of A given B.
- \(P(B|A)\): Probability of B given A.
- \(P(A)\): Prior probability of A.
- \(P(B)\): Probability of B.

**Example:**

We want to calculate the probability of heart disease given a patient's medical details.

The Bayesian Network uses the available medical evidence to estimate the probability of each disease status.

### 3. Dataset

A dataset is a collection of data used for analysis and prediction.

Here, the program uses:

`heart.csv`

It contains patient medical information, including numerical features and a target column.

The target column represents heart disease status.

For this practical:

- `0` = No heart disease.
- `1` = Heart disease.

**Important:** This interpretation assumes the `heart.csv` dataset uses the common binary target encoding.

### 4. Data Preprocessing

Data preprocessing means cleaning and transforming raw data before using it to train a Machine Learning model.

In this practical, preprocessing includes:

- Converting column names into lowercase.
- Handling missing values.
- Converting values into numerical format.
- Discretization of continuous variables.
- Converting variables into categorical format.

### 5. Discretization

Discretization is the process of converting continuous numerical values into a limited number of categories or intervals.

For example:

Suppose age values are:

`22, 35, 48, 60, 72`

After discretization, they may be represented as:

| Numerical Range | Category |
|---|---|
| Lower values | Low |
| Middle values | Medium |
| Higher values | High |

In this practical, numerical features having more than five unique values are divided into three bins.

**Why is discretization used?**

A Discrete Bayesian Network works with discrete states. Therefore, continuous numerical features must be converted into categories.

### 6. Bayesian Estimator

BayesianEstimator is used to estimate the Conditional Probability Distributions (CPDs) of the Bayesian Network.

It calculates probabilities using observed data along with a prior distribution.

In this practical, the prior type is `BDeu`.

### 7. Conditional Probability Distribution (CPD)

A CPD represents the probability of a variable given the values of its parent variables.

Example:

\[
P(\text{Heart Disease} \mid \text{Age, Cholesterol})
\]

It tells us the probability of heart disease for different combinations of age and cholesterol categories.

### 8. Variable Elimination

Variable Elimination is an exact probabilistic inference algorithm used to calculate the probability distribution of a query variable given some observed evidence.

In this practical:

- Query variable = `target`
- Evidence = Patient's medical details

It calculates the probability of both heart disease states based on the selected patient's features.

### 9. Maximum a Posteriori (MAP) Prediction

The program uses `np.argmax()` to select the disease state having the highest predicted probability.

For example:

| Disease Status | Probability |
|---|---:|
| 0 – No disease | 25% |
| 1 – Disease | 75% |

The predicted state is `1`, because it has the highest probability.

Formula:

\[
P(A|B)=\frac{P(B|A)P(A)}{P(B)}
\]

It is the mathematical foundation behind Bayesian probability updating.

### Q3. What is a Directed Acyclic Graph (DAG)?

A DAG is a graph containing directed edges but no directed cycles.

- Directed means edges have a specific direction.
- Acyclic means there is no circular path.

Example:

```text
Age ────────→
Cholesterol ─→ Heart Disease
Blood Pressure →
```

There is no circular connection in this structure.

### Q4. What are nodes and edges in a Bayesian Network?

- **Nodes:** Represent variables such as age, cholesterol and heart disease.
- **Edges:** Represent directed dependency relationships between variables.

### Q5. What is a Conditional Probability Distribution?

A Conditional Probability Distribution (CPD) represents the probability of a variable given the values of its parent variables.

Example:

\[
P(\text{Heart Disease} \mid \text{Age, Cholesterol})
\]

It calculates the probability of heart disease for given age and cholesterol categories.

### Q6. What is Bayesian Estimation?

Bayesian Estimation is a method of estimating probabilities by combining observed data with prior probability information.

It helps estimate the parameters of a Bayesian Network.

### Q7. What is BDeu?

BDeu stands for Bayesian Dirichlet equivalent uniform.

It is a uniform prior used in Bayesian Network parameter estimation.

It helps avoid zero-probability estimates for combinations that were not observed in the training dataset.

### Q8. What is Variable Elimination?

Variable Elimination is an exact inference algorithm used to calculate the probability distribution of a query variable given observed evidence.

In this practical:

- Query variable: `target`
- Evidence: Patient medical details.

### Q9. What is the difference between Training and Inference?

| Training | Inference |
|---|---|
| Learns probability distributions from data. | Calculates probabilities using the learned model. |
| Uses `model.fit()`. | Uses `inference.query()`. |
| Estimates CPDs. | Predicts the target probability. |

### Q10. What is Discretization?

Discretization converts continuous numerical values into a limited number of categories.

Example:

```text
Age = 25 → Low
Age = 45 → Medium
Age = 70 → High
```

The actual category depends on the intervals created from the dataset.

### Q11. Why is Discretization required in this practical?

Because we are using a Discrete Bayesian Network, which works with discrete states rather than continuous numerical values.

### Q12. What is the difference between Discrete and Continuous Bayesian Networks?

| Discrete Bayesian Network | Continuous Bayesian Network |
|---|---|
| Uses discrete variables. | Uses continuous variables. |
| Values are categories or states. | Values are numerical measurements. |
| Example: Low, Medium, High. | Example: Age = 45.5. |

### Q13. What is a Prior Probability?

Prior probability is the probability of an event before considering new evidence.

Example:

The probability of heart disease in the overall dataset before considering a particular patient's medical details.

### Q14. What is Posterior Probability?

Posterior probability is the updated probability of an event after considering available evidence.

Example:

The probability of heart disease after considering the patient's age, cholesterol and other medical details.

### Q15. What is the purpose of `np.argmax()`?

It returns the index of the maximum value in an array.

Here, it identifies which target state has the highest predicted probability.

### Q16. What is the difference between a Bayesian Network and Naive Bayes?

| Bayesian Network | Naive Bayes |
|---|---|
| Represents dependencies using a DAG. | Uses a simplified probabilistic classification model. |
| Can represent more complex relationships. | Assumes features are conditionally independent given the class. |
| Structure can contain different parent-child relationships. | Features are generally modeled as independent parents of the class. |

# 10. Important Technical Points and Limitations

These points are especially useful if the external examiner asks questions beyond the code.

### 1. Why is the target column not discretized?

The target column is already converted into categorical states, generally `0` and `1`. Therefore, it does not require further discretization.

### 2. Why are all features connected directly to the target?

The program uses a predefined network structure in which every feature is a parent of the target.

It is a simple structure designed for predicting the target from medical features.

**Remember:** The edges represent the assumed dependency structure. They do not prove that each medical feature causes heart disease.

### 3. Does this code use a train-test split?

No. The code trains the model using the entire cleaned dataset.

It then selects a patient record from that same dataset for inference.

This means the selected patient may already have been included during training. Therefore, this practical demonstrates Bayesian inference, but it does not provide an unbiased evaluation of prediction accuracy.

### 4. Does this code calculate model accuracy?

No. It calculates probabilities for the selected patient but does not compare predictions against actual labels across a separate test dataset.

To evaluate performance properly, we would need a train-test split and metrics such as:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix

### 5. What happens if the dataset contains more than two target classes?

The model can potentially calculate probabilities for multiple target states. However, the final diagnosis code only checks whether the predicted state is `"1"`.

Any other predicted state will be displayed as `"No Heart Disease Detected"`.

Therefore, this final diagnosis logic is appropriate only when the dataset uses binary target encoding of 0 and 1.

### 6. What happens if the user enters an invalid patient number?

The program handles two cases:

- If the number is outside the valid range, it displays `"Please enter a valid record number."`
- If the input is not an integer, it displays `"Please enter a valid integer."`

The loop continues until valid input is entered.
